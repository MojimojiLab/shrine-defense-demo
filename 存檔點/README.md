# 存檔點 💾

每一步我們做好的東西，檔名開頭是第幾步。卡住了也別擔心：下載檔案，拖進對話串，貼上右邊那句話，就能接著做囉。

AI 每次的反應不同，不保證每一句都一次就成功；它理解錯了，就再講清楚一點。

圖集（spritesheet）是透明背景的 PNG。有些看圖軟體不顯示透明，會把背景畫成黑色或雜色，那是檢視器的問題，不是圖有問題喔。

`清理前的版本/` 是 AI 自己重畫、去背之前的版本，想看前後差別的人才需要。
