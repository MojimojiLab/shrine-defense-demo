## 怎麼在本機打開某一版

遊戲用 ES module，不能直接雙擊 `index.html`，要開一個本機伺服器：

```powershell
cd "完成版\v1-第一版"
python -m http.server 8001
```

然後用瀏覽器開 `http://localhost:8001`。要同時開好幾版，每版換一個埠號，例如 v2 用 8002、v3 用 8003。
