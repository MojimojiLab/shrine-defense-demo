# 神社保衛戰 背景音樂包（BGM）

3 首可以無縫循環的背景音樂，請用循環播放（loop）。響度都約 −20 LUFS，比音效低一截。授權是 **CC0**：可商用、可修改、可再散布，不需署名。

| 檔名 | 用在哪裡 | 循環長度 |
| --- | --- | --- |
| `bgm_title.ogg` | 開始畫面 | 22.9 秒 |
| `bgm_battle.ogg` | 第 1～5 波戰鬥 | 58.2 秒 |
| `bgm_boss.ogg` | 鬼王登場後的鬼王戰 | 24.6 秒 |

切換時建議做短短的淡入淡出（約 0.5～1 秒），例如鬼王降臨時從 `bgm_battle` 換到 `bgm_boss`。勝利或失敗時停止 BGM，播放結算音效。

## 出處

AI 生成：ACE-Step v1.5 XL SFT（MIT 授權，模型卡寫明生成音樂可商用），透過 Runware API 呼叫，再剪成循環段落。生成的音樂以 CC0 釋出。
